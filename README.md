# LISF5002M-Demos
This repository contains some resources for LISF5002M 

Currently this repository only contains clustering about the IMD. These instructions demonstrate the following: 

- Three types of "Feature Leakage" (accidental circular causality, data processing, cross-validation). 
- Proxy variables - note that the smallest areas within the census data - LSOAs - are selected to be statistically homogeneous. This leads LSOA to be a strong proxy for ETHNICITY.

To use this repository during the workshop: 

1. Create a fork - this is your own virtual copy of this repository.  
2. Open the jupyter-notebook `workshop.ipynb` in Code-space and run the cells before Task 1
3. Follow the instructions...
