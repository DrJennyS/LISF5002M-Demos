# LISF5002M-Demos
This repository contains some resources for LISF5002M 

Currently this repository only contains clustering about the IMD. These instructions demonstrate the following: 

- Three types of "Feature Leakage" (accidental circular causality, data processing, cross-validation). 
- Proxy variables - note that the smallest areas within the census data - LSOAs - are selected to be statistically homogeneous. This leads LSOA to be a strong proxy for ETHNICITY.
- Distributional (Paradigm) shift - underlying properties change over time so the quality of the out-of-sample predictions deteriorates over time. It may not be reasonable to continue to use the 2019 index...

To use this repository during the workshop: 

(A) Create a PRIVATE fork - this is your own virtual copy of this repository. 
(B) Download the dataset(s) provided and make sure you know where they are located within your file structure.  
(C) Open the jupyter-notebook `workshop.ipynb` in Code-space
(D) Follow the instructions...
